The Challenge: From Text to Functional Code

While the LinkedIn Learning module focused on generating marketing text with Few-Shot Learning, I chose to demonstrate the concept's power by tackling a more complex challenge: the generation of a fully functional web-based Tetris game.

LinkedIn Challenge Requirements (Reimagined):

  • Objective: Generate a complex, interactive web asset (Tetris game).
  • Method: Utilize Few-Shot Learning to establish core coding patterns and logic within Claude.
  • Output Constraints: Functional, well-structured, single HTML file (as generated by Claude's Artifact).

Leveraging Claude's Artifacts for Code Generation

A key aspect of this project was exploiting Claude's "Artifacts" feature. This powerful capability allows Claude to not only generate code but also to execute and display it within its interface. This live execution and validation loop significantly streamlines the development process when prompting for functional code. As stated in the course, "Los artefactos permiten a Claude ejecutar el código que se genera y son extremadamente poderosos porque le permiten aprovechar sus habilidades de codificación."

Few-Shot Prompt Strategy for Tetris Logic

To guide Claude in generating the Tetris game, a Few-Shot approach was employed. By providing a few examples of fundamental game elements – such as the data structure for a Tetromino or a basic movement function – Claude was able to infer the required patterns, logic, and overall game structure. This showcases how precise examples can lead to complex functional outputs.

Simulated Claude Prompt: Few-Shot for Tetris Game Generation
# ROLE: Eres un desarrollador experto de juegos en JavaScript.
ROLE: Expert JavaScript Game Developer
INSTRUCTION: Genera un juego de Tetris completo en un único archivo HTML (HTML, CSS y JS combinados). El juego debe tener un diseño clásico, seguimiento de puntuación, progresión de niveles y una vista previa de la siguiente pieza. Toda la lógica del juego debe estar dentro de las etiquetas script. El código debe ser claro y bien comentado.

EXAMPLE 1 (Estructura de Tetromino - L-shape):
  // Representación del tetromino en forma de L
  const lTetromino = [
      [1, width+1, width*2+1, 2],
      [width, width+1, width+2, width*2+2],
      [1, width+1, width*2+1, width*2],
      [width, width*2, width*2+1, width*2+2]
  ];

EXAMPLE 2 (Función de movimiento básico - moveDown):
  function moveDown() {
      undraw();
      currentPosition += width;
      draw();
      freeze();
  }

# Ahora, genera el archivo HTML completo del juego de Tetris.
OUTPUT: [Claude genera el archivo HTML completo del Tetris aquí, incluyendo CSS y JS, como el archivo que tienes en 'tetris-game/index.html']

Este enfoque va más allá de la generación de texto, demostrando cómo la ingeniería de prompts puede ser utilizada para crear activos funcionales complejos. La clave residió en la claridad de los ejemplos y la precisión en la solicitud para aprovechar las capacidades de codificación de Claude.
