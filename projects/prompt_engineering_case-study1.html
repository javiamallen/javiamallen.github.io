The Challenge & Prompt Strategy

The goal was to engineer a prompt that not only generated text but also forced strict format compliance and scaled to produce a final, usable file (PPTX).

LinkedIn Challenge Requirements:

  • Objective: Create a presentation outline/slides.
  • Audience: Tech Consultants (A high-level persona).
  • Output Constraints: 6 slides, 5 points per slide, max 6 words per point.
Prompt Execution: Structured Instruction (Prompt-to-Code)

Generación y Hosting del PPTX: Un Activo Dinámico y Auto-Servido

El esquema de presentación, inicialmente generado por ChatGPT en formato de texto estructurado, fue posteriormente utilizado como la entrada para un script de Python proporcionado por ChatGPT. Este script, al ser ejecutado, interpreta la estructura del texto y construye dinámicamente el archivo PowerPoint (.pptx). Al alojarlo en GitHub Pages, el activo resultante se convierte en un recurso auto-servido y disponible de forma dinámica.

`generate_ppt.py` (Simplified Example)
from pptx import Presentation
from pptx.util import Inches

def create_presentation_from_text(text_outline, output_filename="presentation.pptx"):
    prs = Presentation()
    
    # Divide el esquema en diapositivas
    slides_data = text_outline.strip().split('\n\n')

    for slide_text in slides_data:
        lines = slide_text.split('\n')
        if not lines: continue
        
        # Asumiendo que el título está en la primera línea
        title = lines[0] if lines[0].startswith("Slide") else "Untitled Slide" 
        if title.startswith("Slide"):
            title = title.split(':', 1)[1].strip() # Eliminar "Slide X:"

        content_points = [line.strip('- ') for line in lines[1:] if line.strip()]

        # Añadir diapositiva con título y viñetas
        slide_layout = prs.slide_layouts[1] # Layout de Título y Contenido (común)
        slide = prs.slides.add_slide(slide_layout)
        title_obj = slide.shapes.title
        body_obj = slide.shapes.placeholders[1]

        title_obj.text = title

        tf = body_obj.text_frame
        tf.clear() 
        
        for point in content_points:
            p = tf.add_paragraph()
            p.text = point
            p.level = 0 

    prs.save(output_filename)
    print(f"Presentación '{output_filename}' generada exitosamente.")
